A token launch radar built from a sealed DefiLlama snapshot: it ranks 198 protocols that record no token by implied launch value — each valued from the market-cap/TVL multiples of tokenized peers in its own category, adjusted for 7-day momentum, age and chain breadth — and ships a fully offline dashboard with a detail view and a concrete farm plan for every protocol on the board.

## Run it

```sh
node main.ts --input /input/snapshot.json --output /output
```
